🔍 INTERPRETING RESULTS:

  1. Convergence comparison (Final Loss)
     - If Muon ≈ SGD/Adam: Good! Layer-wise is sufficient
     - If Muon >> others: Cross-layer info crucial?

  2. Oracle alignment (cosine_sim)
     - > 0.7: Muon matches oracle well (despite ignoring cross-layer)
     - 0.5-0.7: Moderate divergence
     - < 0.5: Cross-layer effects significant

  3. Speed (Time/Step)
     - Muon should be ≈ same as SGD (no major overhead)
